# School Advertisement Program

학교 광고 송출 프로그램

라즈베리 파이에서 실행하는 Flask 기반 학교 디지털 게시판입니다. 별도 프런트엔드 빌드나 외부 폰트 연결이 필요하지 않습니다.

## 실행하기 (Raspberry Pi OS)

```bash
git clone https://github.com/onlytt10/scholl-tv-ad.git
cd scholl-tv-ad
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

- 파이에서 관리자 화면: `http://localhost:5000`
- 같은 네트워크의 다른 기기: `http://라즈베리파이-IP:5000`
- TV 전체 광고: `/display/all`
- 학년별 TV: `/display/1`, `/display/2`, `/display/3` (각 학년 + 공통 광고)
- Chromium에서 TV 주소를 열고 F11을 누르면 전체 화면이 됩니다.

## 기존 데이터 옮기기

기존 프로그램을 종료하고 `uploads` 폴더와 `playlist.txt`를 먼저 백업한 뒤, 이 프로젝트의 `app.py` 옆으로 복사하세요. `all_파일명`, `1_파일명` 등 기존 파일명과 목록 순서를 유지합니다. 실행 위치와 관계없이 이 프로젝트 폴더의 데이터를 사용합니다. 원본 첨부 코드의 관리자 HTML과 재생 스크립트 일부가 누락되어 해당 부분을 재구성했습니다.

## 주요 기능과 사용 방법

- 화면 크기에 맞는 관리자 화면, 이미지 썸네일, 검색, 학년 필터, 광고 개수 표시
- 이미지·영상 업로드와 업로드 중 안내 (한 번에 한 파일, 최대 1GB)
- 광고 왼쪽의 ⠿ 손잡이를 마우스나 터치로 드래그하면 재생 순서가 바로 저장됩니다. 화면 가장자리로 끌면 자동으로 스크롤됩니다. Esc로 취소할 수 있습니다.
- 키보드는 손잡이에 Tab으로 이동 → Space로 잡기 → 위/아래 방향키로 이동 → Enter로 저장합니다.
- 순서 변경은 검색을 비우고 전체 대상을 선택했을 때 가능합니다. 저장 실패 시 이전 순서로 복구하며, 다른 화면에서 목록이 변경된 경우 새로고침 안내를 표시합니다.
- 삭제 시 파일명을 보여주는 확인창. 취소 또는 Esc로 닫을 수 있습니다. JavaScript가 꺼져 있으면 별도 확인 페이지가 열립니다.
- 삭제·순서 변경은 POST 요청으로만 실행되며, 확인 페이지를 여는 것만으로 삭제되지 않습니다.
- 같은 파일명 업로드 시 `(2)`, `(3)`을 붙여 기존 파일을 보존합니다.
- TV는 이미지 5초, 영상 끝까지 재생하고 한 주기가 끝나면 목록을 다시 읽습니다. 빈 목록은 15초마다 확인합니다.
- TV 영상은 브라우저 자동재생을 위해 **기본 음소거**입니다. 소리가 필요하면 별도 설정 변경이 필요합니다.
- MP4/WebM/MOV 파일을 받지만 실제 재생은 Chromium의 코덱 지원에 달려 있습니다. 파이에서는 H.264 MP4로 먼저 확인하세요.

## 운영 및 GitHub

현재 버전에는 관리자 로그인 기능이 없습니다. 신뢰하는 학교 내부 네트워크에서만 사용하고 인터넷에 포트를 공개하지 마세요. Flask 기본 서버는 기능 확인용입니다. 상시 운영 시 별도 WSGI 서버와 접근 제어를 구성하세요. 동시에 여러 서버 프로세스를 사용하는 구성은 텍스트 목록의 동시 쓰기 보호를 추가해야 합니다.

`SECRET_KEY` 환경변수에 고정된 임의 문자열을 지정하면 재시작 후에도 관리자 세션을 유지할 수 있습니다. 지정하지 않으면 재시작 때 새 키가 만들어지므로 관리자 페이지를 새로고침하세요. 키는 GitHub에 올리지 마세요.

`.gitignore`가 업로드 파일·재생 목록·가상환경·환경설정 파일을 제외합니다. 학교 광고 자료는 저장소에 포함하지 않습니다.
